# 文档导航

本目录收录 BootstrapBlazor 仓库的开发与贡献指南，帮助贡献者和 AI Agent 按任务找到相应约定。组件库的安装与使用说明请参阅仓库根目录的 [README](../README.md)。

## 开发与贡献指南

| 文档 | 适用场景 |
| --- | --- |
| [组件规范与自检](agents/component-checklist.md) | 修改组件、参数、样式、本地化或组件示例 |
| [依赖说明](agents/dependencies.md) | 排查依赖源码或添加、更新依赖 |
| [仓库级 Agent Skills](agents/skills.md) | 配置 Agent Skill，或使用仓库级发布说明、代码审查、Issue / PR skill |
| [提交与 PR 指南](agents/pr-guide.md) | 创建分支、提交、推送或创建、更新 Issue / PR |
| [Git Commit Message Template](agents/commit_msg_template.md) | 编写提交信息 |

## 查阅约定

- 开始对应任务前，先阅读上表中适用的指南，并遵守仓库根目录的 [AGENTS.md](../AGENTS.md)。
- 新增或调整本目录中的指南时，请同步更新本页索引。
- 本页用于导航，不重复维护各指南中的具体规范；如规则不一致，以对应指南和根目录 `AGENTS.md` 为准。
