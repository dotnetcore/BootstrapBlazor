# Git Commit Message Template

## 格式:

`<type>(<scope>): <subject>`

## 提交类型 (type) 说明

- feat:     新增功能
- fix:      修复缺陷
- docs:     仅修改文档
- style:    代码格式调整（不影响代码逻辑，如空格、分号）
- refactor: 代码重构（非新增功能也非修复缺陷）
- perf:     性能优化
- test:     增加或修改测试
- build:    影响构建系统或外部依赖（如 gulp、webpack、npm）
- ci:       修改 CI 配置文件或脚本（如 Jenkins、GitHub Actions）
- chore:    其他不修改 src 或 test 文件的变更
- revert:   回滚上一次提交
